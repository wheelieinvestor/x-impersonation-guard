# FAQ

## Does this remove impersonators?

No. It detects and reports them. X decides enforcement.

## Can it report through the X API?

No. X does not offer a programmatic impersonation report endpoint.

## Is scrape mode reliable?

Less reliable than API mode. It exists as a fallback for users without X API credentials.

## Can I auto-submit reports?

Yes, but it is off by default and intentionally warned. Manual review is safer.
